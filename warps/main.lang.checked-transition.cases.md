# Hand-authored case matrix

Specified before implementation. Every group will have named executable cases;
no row below is an observation or accepted result.

| Group | Required expected outcomes |
| --- | --- |
| CE.identity | exact source/scope/alias/transition checked; wrong values mismatched; local shorthand ambiguous; repeated letters resolve by qualified identity |
| CE.policy | unsupported/missing/unknown fields malformed; duplicate requirements/cases ambiguous; empty roles malformed; absent required inputs mismatched |
| CE.attempt | absent receipt absent; manual/native ACK declared; wrong producer/scope/source/policy hash rejected; duplicate case IDs ambiguous; missing case mismatched |
| CE.results | green/pass checked; red/fail failed; false passing labels cannot mask failed aggregates; zero/skipped/inconsistent/overflow counts failed |
| CE.drift | independently mutate spec/implementation/test/config/runner/behavior/policy/result; current acceptance lost; old observation retained |
| CE.bounds | source, JSON, ordinary input, aggregate bytes, file count, requirement/case count at and beyond limits; no unbounded transitive reads |
| CE.paths | Unicode path roundtrip; absolute/drive/UNC/dot-dot/backslash/NUL/directory/missing/symlink/junction escape rejected |
| CE.query | full compact/expanded identities and alias/boundary/coverage agreement; packet unchanged; no recursive scan; bytes unchanged and command trap not executed |
| CT.confirm | same dry assessment; valid confirmation exact E0->Ef plus status; no confirmation no writes; evidence rejections preserve E0 |
| CT.compat | existing companion receipt and query defaults unchanged; checked/legacy flag conflicts rejected |
| CT.collisions | occupied Ef/status and unsafe transaction ancestor rejected; no overwrite; exact accepted replay idempotent; conflicting attempt fails |
| CT.race | drift after planning and before mutation rejected; explicit read-set freshness, no global concurrency claim |
| CT.recover | faults before/after intent, linking, unlinking, status publication; no false ACK; restart and explicit recovery or bounded blocker; drift/collision blocks recovery |
| CT.reentry | actual new processes reconstruct query and status; history remains accepted while changed live inputs assess stale; required Cargo/clippy and pure-command regressions |

Implement red tests at the actual shared evaluator seam before behavior. A stub
may establish a callable boundary, but a missing command/import alone is not the
red evidence. Preserve that stub baseline and exact failing assertions; replace
behavior without weakening assertions. Test fixtures are independent authored
expectations, not reports generated by the evaluator under test.
